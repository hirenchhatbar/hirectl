# Docs

- Keep `docs/DIRECTORY_STRUCTURE.md` and `docs/TECH_STACK.md` up to date: any change that adds, removes, moves or repurposes a file or directory, or changes a language, dependency, version, tool or image, updates them in the same change.
- Keep `README.md` up to date: any change to what the app does, its commands or options, integrations, data dir, or `make` targets it lists updates it in the same change. Keep it a short overview; details belong in `docs/`.
- Keep `docs/CLI.md` up to date: any change that adds, removes or renames a command, option or argument, or changes its default, behaviour, output, files read or written, or TUI keys, updates it in the same change.
